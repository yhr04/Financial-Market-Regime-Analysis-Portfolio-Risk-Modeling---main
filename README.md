# Capstone Project

This file serves as an overview of the contents of this repository.

## Demo Instructions

Run the .ipynb file to see a demo version of our project.

- `project_demo.ipynb`
  - Simplified version of our Elastic Net model that pulls data directly from APIs.
- `project.html`
  - Version of the demo notebook with all outputs already generated.

## Full Project Files
> Require local PostgreSQL setup 

- `capstone.sql`
  - PostgreSQL database schema.

- `insert_data_with_fomc.ipynb`
  - Loads the complete dataset into the configured PostgreSQL database.

- `stat170ARollingNetandArimax.ipynb`
  - Implementation of the Elastic Net and ARIMAX models, including visualizations and model eval.
    
- `stat170agraphs.ipynb`
  - Implementation of the Gradient Boosting model, including visualizations and model eval.
    
- `stat170agraphs_3months.ipynb`
  - Gradient Boosting model but with 3-month windows (as opposed to 1)
